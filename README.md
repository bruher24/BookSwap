# BookSwap
Суть: Пользователи могут выкладывать книги, которые готовы отдать, и брать другие книги в обмен.  
Фичи:  
* Регистрация + JWT-авторизация
* Поиск книг по названию/автору
* Система рейтинга пользователей (чтобы избежать мошенников)
* Уведомления о новых книгах (через Email/Telegram)
* Docker-контейнеры с PostgreSQL и Redis (для кеша/очередей)
* PHPUnit-тесты для API и бизнес-логики
